# VoxDeck

An AI-powered voice and communication workspace designed to streamline fast business pitches and audio workflow management.

- **Voice AI Integration:** Seamlessly generate, translate, and synthesize multi-lingual business pitches.
- **Multilingual Support:** Built-in support for multiple languages with native text-to-speech workflows.
- **Fast Performance:** Optimized for low latency and instant script formatting.
- **Clean Interface:** Minimalist and intuitive layout designed for quick access and navigation.


## TechStack


- **Frontend:** HTML5, CSS3, JavaScript 
- **AI / Processing:** Advanced Voice and Speech-to-Text APIs
- **Hosting & Deployment:** Vercel 

- **Voice & AI Tools:** Wispr Flow (used for rapid development / voice input workflows)
- **AI Processing:** Advanced Speech-to-Text & Text-to-Speech APIs
